# GBA / GBC Emulator for Android

A native Android emulator app focused on **Game Boy Advance, Game Boy Color, and original Game Boy** games.

- [Agent instructions](AGENTS.md) — mandatory rules for all coding agents, including Arena.ai.
- [Implementation plan](docs/IMPLEMENTATION_PLAN.md) — product scope, architecture, milestones, production gates, and live completion ledger.
- [Reference screenshots](docs/reference-images/README.md) — the eight supplied UI references and how they map to the planned app.

## Current status

**Planning baseline only.** The repository was empty when planning began. No emulator engine, Android project, ROM assets, or BIOS files have been added yet.

## Product direction

Build an offline-first Android app with a browsable local game library, a responsive virtual handheld (portrait and landscape), save/load states, cheats, configurable core options, and Bluetooth/USB game-controller support.

The app will not bundle commercial ROMs, copyrighted game artwork, or proprietary BIOS files. Users will select games and any optional firmware they are entitled to use.
